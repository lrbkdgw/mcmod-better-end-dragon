# Better End Dragon（更强的末影龙）

一个 **Minecraft Java 1.20.1 / NeoForge** 模组：加入四种特殊水晶、一条拥有两个阶段的强化末影龙 Boss 战，
以及在最终决战之后开启的全新维度 **冥界**。

编译完全由 GitHub Actions 完成（`.github/workflows/build.yml`），每次推送都会构建并上传 `betterenddragon-1.0.0.jar`。

---

## 一、物品

| 物品 | 获取方式 | 外观 |
| --- | --- | --- |
| **凋灵水晶** | 合成：末影水晶 + 4 下界之星（四角）+ 4 钻石块（四边） | 变黑的末影水晶 |
| **下界水晶** | 合成：末影水晶 + 4 下界合金块（四角）+ 4 下界岩（四边） | 下界岩色的末影水晶 |
| **深谙水晶** | 用**末影水晶的爆炸伤害**击败监守者，必定掉落 | 深蓝色的末影水晶 |
| **真理水晶** | 被末影水晶爆炸摧毁的附魔书有 0.2% 概率转化（宝藏型附魔书为 1%） | 带附魔光效的末影水晶 |

四种水晶都可以像末影水晶一样放置在黑曜石 / 基岩上，放置时会生成对应颜色的水晶实体。

## 二、强化末影龙

在末地传送门四周**各放置一个**上述四种水晶（每种一个）来复活末影龙，就会得到强化后的末影龙。

**通用**

* 附近 500 格内没有玩家时自动消失（下一次复活仍为强化版本）。
* Boss 血条显示为“强化末影龙”。

**第一阶段**

* 生命值 300%（600 点），造成伤害 150%。
* 所有末影水晶都会被铁笼包围；末地内的玩家持续获得**挖掘疲劳 IV**。
* 更频繁的俯冲攻击（约每 5 秒一次）；俯冲命中玩家后玩家获得**虚弱 III**、**缓慢 I**，末影龙回复 10% 生命值。
* 降落 / 停驻在传送门上时受到的伤害降低 50%。
* 被击败后不会死亡，而是原地复活并进入第二阶段（所有末影水晶恢复，但铁笼不会恢复）。

**第二阶段**

* 生命值 300%，造成伤害 150%，**免疫弹射物伤害**。
* 末影水晶被摧毁后 10 秒恢复；末影水晶不再为末影龙回血。
* 每秒回复 5 点生命值，受到的伤害降低 80%；被末影水晶的爆炸命中后该减伤失效 20 秒。
* 每 30 秒在玩家附近 8~20 格召唤**强化末影螨**：
  * 生命值 800%（64 点），只跟随玩家、只对玩家有敌意；
  * 命中玩家后玩家获得**虚弱 III**、**缓慢 II**；
  * 生成 60 秒内未被击败则被末影龙吸收，并对整个末地主岛造成 50 点爆炸伤害。
* 被击败后 20 秒内不会死亡：期间每秒召唤一只强化末影螨，每 4 秒对主岛造成 10 点爆炸伤害。
* 彻底死亡后产生一次极剧烈的爆炸，强制 500 格内的玩家进入**死亡动画**。
  该动画**不是真正的死亡**：不掉落任何物品，极限模式也不会因此结束。点击“重生”后进入冥界。

## 三、冥界

* 一条长 500 格的道路，两旁有栏杆与灵魂灯笼，四周为虚空。
* 进入时固定获得 **500000 点经验**。
* 每 50 格一个站点（共 10 个），分别是：

| 站点 | 内容 |
| --- | --- |
| 50 | 鞘翅 ×8、下界合金块 ×16、钻石块 ×128、绿宝石块 ×128、红石块 ×256、青金石块 ×256、铁块 ×256、金块 ×256、铜块 ×256 |
| 100 | 附魔金苹果 ×256、全部 17 种锻造模板各 ×32、紫水晶碎片 ×256、下界之星 ×8、潜影壳 ×128 |
| 150 | 抗性提升 V / 60 分钟 ×9，生命恢复 X / 120 分钟 ×9，力量 255 / 20 秒 ×9 |
| 200 | 不可破坏的全套钻石装备 |
| 250 | 不可破坏的鞘翅 + 烟花 18×64 |
| 300 | 时运 X、效率 X、不可破坏的钻石镐 / 锄 / 斧 |
| 350 | 锋利 X、抢夺 X、火焰附加 X、不可破坏的钻石剑 |
| 400 | 灯塔：登顶激活**永存装置** → 强制开启死亡不掉落 |
| 450 | 灯塔：登顶激活**翱翔装置** → 获得创造飞行能力（持久保存） |
| 500 | 灯塔：登顶激活**归乡装置** → 离开冥界，回到主世界出生点 |

奖励全部直接放在潜影盒中（不是战利品表），物品装不下时会自动使用多个潜影盒。
灯塔侧面有梯子，爬到顶端右键中央的装置即可激活。

## 四、管理员指令

需要 2 级权限，便于测试：

```
/betterenddragon crystals     # 获得四种水晶各一个
/betterenddragon arm          # 让下一次末影龙复活成为强化版本
/betterenddragon empower      # 立即强化当前维度中的末影龙
/betterenddragon stage2       # 让强化末影龙直接进入第二阶段
/betterenddragon fakedeath    # 触发死亡动画（用于测试冥界入口）
/betterenddragon underworld   # 直接进入冥界
```

## 五、构建

本仓库使用 NeoGradle 6 + NeoForge `1.20.1-47.1.106`，目标 Java 17。

* **GitHub Actions**：推送到任意分支后自动运行 `Build` 工作流，产物在 Actions 页面的
  `betterenddragon-jar` 中下载。
* **本地构建**：

```bash
./gradlew build          # 产物位于 build/libs/
./gradlew runClient      # 开发环境启动客户端
```

贴图由 `tools/generate_textures.py` 程序化生成（不含任何原版素材的复制），
如需修改配色直接改脚本后重新运行即可。

## 六、实现备注

* 四种水晶实体继承自原版 `EndCrystal`，因此原版的末影龙复活仪式可以直接识别它们；
  渲染时复用原版模型并整体着色（真理水晶额外叠加附魔光效）。
* 强化状态保存在末影龙实体的 Forge 持久化数据中，阶段、计时器等在存档重载后依旧有效；
  末地维度的仪式状态、水晶重生计时器保存在 `SavedData` 中。
* “死亡动画”是模组自定义的界面 + 网络包实现，服务端不会真的让玩家死亡，
  因此不掉落物品、也不会结束极限模式世界。
