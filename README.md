# Better End Dragon（更强末影龙）

面向 **Minecraft Java 1.20.1 / NeoForge** 的模组。使用 GitHub Actions 自动编译。

* 加载器：NeoForge `1.20.1-47.1.106`（兼容 MinecraftForge 47.x）
* 构建工具：Gradle 8.14.5 + ModDevGradle（legacyforge）
* Java：17

## 构建

推送到本仓库任意分支即会触发 `.github/workflows/build.yml`，产物 jar 会作为
Artifact（`betterenddragon-jar`）上传。本地构建：

```bash
./gradlew build
```

生成的 jar 位于 `build/libs/`。

## 内容

### 四种特殊末影水晶

它们都是"可放置的末影水晶"，可以像原版末影水晶一样放在黑曜石/基岩上，
也可以用于末影龙的复活仪式。

| 物品 | 获取方式 | 外观 |
| --- | --- | --- |
| 凋灵水晶 `wither_crystal` | 合成：末影水晶 + 4 下界之星 + 4 钻石块 | 变黑的末影水晶 |
| 下界水晶 `nether_crystal` | 合成：末影水晶 + 4 下界合金块 + 4 下界岩 | 下界岩颜色的末影水晶 |
| 深谙水晶 `deep_crystal` | 用末影水晶的爆炸伤害击杀监守者，必定掉落 | 深蓝色末影水晶 |
| 真理水晶 `truth_crystal` | 被末影水晶爆炸摧毁的附魔书有 0.2% 概率转化（宝藏型附魔书 1%） | 带附魔光效的末影水晶 |

合成配方（`末影水晶` 位于中心）：

```
凋灵水晶            下界水晶
N D N              K R K          N = 下界之星   D = 钻石块
D E D              R E R          K = 下界合金块 R = 下界岩
N D N              K R K          E = 末影水晶
```

### 强化末影龙

**当复活仪式使用的四个水晶正好是上述四种各一个时**，召唤出来的末影龙会被强化。

一阶段：

* 500 格内没有玩家时自动消失
* 生命值 300%（600），造成的伤害 150%
* 所有黑曜石柱上的末影水晶都套上铁笼
* 范围内玩家始终获得挖掘疲劳 IV
* 每 5 秒强制发动一次俯冲攻击；命中玩家 → 玩家获得虚弱 III + 缓慢 I，末影龙回复 10% 生命
* 降落/着陆期间受到的伤害 −50%
* 被击败时不会死亡，而是进入二阶段

二阶段：

* 恢复所有末影水晶（**不恢复**铁笼；残留铁笼会被清除）
* 水晶被摧毁后 10 秒重新生成
* 水晶不再为末影龙回血
* 生命值 300%，造成的伤害 150%，**免疫弹射物伤害**
* 每秒回复 5 点生命，受到的伤害 −80%；被末影水晶的爆炸命中后该减伤失效 20 秒
* 每 30 秒在玩家附近 8~20 格召唤强化末影螨（生命值 800%，只追击玩家；攻击造成虚弱 III + 缓慢 II）。
  60 秒内未被击杀则被末影龙吸收，引发覆盖整座主岛的爆炸（50 点伤害）
* 被击败后进入 20 秒的"垂死挣扎"：每秒召唤一只强化末影螨，每 4 秒造成一次覆盖主岛的爆炸（10 点伤害）
* 彻底死亡时产生终焉爆炸：500 格内的玩家被强制播放**死亡动画**
  （并非真正死亡——不掉落物品、极限模式不会结束），随后进入【冥界】

### 冥界（`betterenddragon:netherworld`）

一条沿 +X 方向、长 500 格的路，两侧有栏杆与灯。进入时固定获得 **500000 点经验**。
每 50 格有一个站点（共 10 个），前 7 个是**固定内容**的潜影盒奖励箱（不是战利品箱），
后 3 个是特殊灯塔：

1. 鞘翅 ×8、下界合金块 ×16、钻石块 ×128、绿宝石块 ×128、红石块 ×256、青金石块 ×256、铁块 ×256、金块 ×256、铜块 ×256
2. 附魔金苹果 ×256、全部 17 种锻造模板各 ×32、紫水晶碎片 ×256、下界之星 ×8、潜影壳 ×128
3. 抗性提升 V（60 分钟）×9、生命恢复 X（120 分钟）×9、力量 255（20 秒）×9
4. 不可破坏的全套钻石装备
5. 不可破坏的鞘翅 + 18×64 烟花火箭
6. 时运 X / 效率 X、不可破坏的钻石镐、钻石锄、钻石斧
7. 锋利 X / 抢夺 X / 火焰附加 X、不可破坏的钻石剑
8. 灯塔 · 魂锚装置 → 强制开启 `keepInventory`
9. 灯塔 · 暮翼装置 → 获得创造飞行能力（死亡/换维度后保留）
10. 灯塔 · 归乡装置 → 离开冥界，回到主世界出生点

> 灯塔顶部的装置需要沿梯子爬上塔顶后右键激活。
