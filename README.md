# Better End Dragon

NeoForge 1.20.1 mod which adds four ritual crystals, an enhanced two-phase Ender Dragon encounter, and the Netherworld reward path.

## Build

Requires Java 17. Run `./gradlew build`; GitHub Actions builds and uploads the jar automatically on every push and pull request.

## Gameplay

Craft Wither, Nether and Deep Dark crystals. Truth Crystals are obtained from enchanted books destroyed by End Crystal explosions. Hold one of each crystal and right-click an End Portal block to begin the enhanced fight. The Netherworld and its reward caches are generated by the dragon's final death sequence.
